Commons, with boundaries

Preview safely. Choose intentionally.

Every listing can state its own creator-granted reuse rights. These are metadata for people to review, not automated legal enforcement. Price is informational in this pilot; checkout and payouts are not available.

Previews use a restrictive sandbox and fixed demo behavior. Submitted snippets are displayed as text, not run. Source maps can expose original source and are fetched only if a user opens the link; they do not make code safe.

Each component should declare only the capabilities it needs. This static pilot cannot enforce permissions in downstream apps. Real extension installs need a reviewed package format, explicit host permissions, sandboxing, and a backend for shared accounts and moderation.
